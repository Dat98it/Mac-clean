# Mac Clean 0.2.1

## Sửa lỗi

- **Mở cửa sổ ở desktop đang dùng:** trước đây cửa sổ Mac Clean chỉ nằm ở desktop (Space) nơi nó được mở lần đầu. Khi sang desktop khác và mở Mac Clean từ Dock, thanh menu, Spotlight hay Finder, macOS lại chuyển về desktop cũ. Giờ cửa sổ chính, Cài đặt và Gợi ý dọn dẹp đi theo bạn sang desktop đang dùng. Cửa sổ đang thu nhỏ trong Dock cũng được mở lại.

Ngoài bản sửa này, app không có gì thay đổi so với 0.2.0. Cửa sổ đang ở chế độ toàn màn hình vẫn có desktop riêng, nên macOS vẫn chuyển sang desktop đó.

## Cài đặt

Mở `MacClean-0.2.1.dmg`, kéo Mac Clean vào Applications (thay bản cũ). Chạy trên macOS 15 trở lên, máy Apple Silicon. App ký ad-hoc, chưa notarize: lần đầu mở, bấm **Xong** (đừng bấm "Chuyển vào Thùng rác"), rồi vào **Cài đặt hệ thống → Quyền riêng tư & Bảo mật → Vẫn mở**.

Bản build mới có chữ ký ad-hoc khác bản trước, nên có thể phải cấp lại Full Disk Access: gỡ Mac Clean khỏi danh sách Full Disk Access (nút **−**), bấm **+** và chọn lại.

Kiểm tra file tải về bằng mã SHA-256 trong file `.sha256` đính kèm.
