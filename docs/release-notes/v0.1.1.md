# Mac Clean 0.1.1

## Có gì mới

- **App icon mới:** một kính lúp soi vào ổ đĩa của Mac. Bên trong là các thư mục xếp từ lớn đến nhỏ, thư mục lớn nhất được tick. Icon nói đúng cách dùng app: nhìn rõ cái gì chiếm chỗ, tự chọn, rồi dọn an toàn.

Ngoài icon, app không có gì thay đổi so với 0.1.0.

## Cài đặt

Mở `MacClean-0.1.1.dmg`, kéo Mac Clean vào Applications (thay bản cũ nếu có). App ký ad-hoc, chưa notarize: lần đầu mở, bấm **Xong** (đừng bấm "Chuyển vào Thùng rác"), rồi vào **Cài đặt hệ thống → Quyền riêng tư & Bảo mật → Vẫn mở**. Bản universal, chạy trên Apple Silicon và Intel, macOS 14 trở lên.

Bản build mới có chữ ký ad-hoc khác bản trước, nên nếu đã cấp Full Disk Access cho bản 0.1.0 thì có thể phải cấp lại: gỡ Mac Clean khỏi danh sách Full Disk Access, bấm **+** và chọn lại.

Nếu Dock hoặc Finder vẫn hiện icon cũ, đó là do macOS lưu cache icon; thường hết sau khi mở lại app hoặc đăng xuất rồi đăng nhập lại.

Kiểm tra file tải về bằng mã SHA-256 trong file `.sha256` đính kèm.
