# Mac Clean 0.1.2

## Có gì mới

- **Icon mới trên thanh menu:** một ổ đĩa đang được chổi quét, kèm ngôi sao lấp lánh. Nhìn là biết đây là app dọn dẹp ổ đĩa. Icon tự đổi màu theo thanh menu sáng hay tối, như các icon khác của macOS.

Ngoài icon thanh menu, app không có gì thay đổi so với 0.1.1.

## Cài đặt

Mở `MacClean-0.1.2.dmg`, kéo Mac Clean vào Applications (thay bản cũ nếu có). App ký ad-hoc, chưa notarize: lần đầu mở, bấm **Xong** (đừng bấm "Chuyển vào Thùng rác"), rồi vào **Cài đặt hệ thống → Quyền riêng tư & Bảo mật → Vẫn mở**. Bản universal, chạy trên Apple Silicon và Intel, macOS 14 trở lên.

Bản build mới có chữ ký ad-hoc khác bản trước, nên nếu đã cấp Full Disk Access cho bản cũ thì có thể phải cấp lại: gỡ Mac Clean khỏi danh sách Full Disk Access, bấm **+** và chọn lại.

Kiểm tra file tải về bằng mã SHA-256 trong file `.sha256` đính kèm.
